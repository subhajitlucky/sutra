# Changelog

## 0.10.1 — 2026-10-23

- Added `sutra --version` and `python -m sutra_lang --version`.
- Added CLI smoke tests for version, help, parse, and demo.
- Added a Python 3.11/3.12/3.13 CI matrix and distribution build validation.
- Added a PyPI Trusted Publishing workflow for future releases.
- Documented the `sutra-a2a` distribution name and `sutra_lang` import package.

## 0.10.0 — 2026-10-23

- First PyPI release as `sutra-a2a`.
- Renamed the import package to `sutra_lang` to avoid the existing `sutra` PyPI package.
- Added packaging metadata, `MANIFEST.in`, and publishing notes.
